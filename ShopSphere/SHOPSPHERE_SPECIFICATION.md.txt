SHOPSPHERE
RTU Advanced Java / Java Enterprise E-Commerce Project
Complete Student Project Development Guide
This guide is based on the RTU syllabus provided: Swing, MVC Architecture, Applets, JDBC, java.net networking, Client-Server, RMI, RMI Registry, Naming/JNDI, Serialization, Internationalization, J2EE architecture, N-tier applications, HTTP, Web Containers, Servlets, Sessions, Events, Filters, JSP, EL, Tag Extensions, JSP Fragments, Tag Files and JSTL.
 
1. Project Overview
ShopSphere is a complete Java E-Commerce Management System designed as a final practical project. The project is deliberately structured so that students can demonstrate the major RTU Advanced Java topics inside one coherent application.
The main customer experience is a modern web store. Additional desktop, networking and distributed-service modules demonstrate the syllabus topics that do not naturally belong inside a browser application.
2. Project Objectives
•	Build a complete E-Commerce application using Java and MVC/layered architecture.
•	Use Swing for a desktop administration module.
•	Use JDBC and MySQL for persistent data.
•	Implement Java networking with Socket and ServerSocket.
•	Implement RMI and the RMI registry for a remote inventory service.
•	Demonstrate object serialization.
•	Apply J2EE, HTTP, web-container and N-tier concepts.
•	Build the customer application using Jakarta Servlet and JSP on Apache Tomcat.
•	Use sessions, cookies, listeners and filters in meaningful features.
•	Use JSP EL, JSTL, JSP fragments and tag files.
•	Provide an explicit RTU syllabus-to-project mapping.

11. JDBC and DAO Layer
Create DAO classes such as UserDAO, ProductDAO, CategoryDAO, CartDAO, OrderDAO, OrderItemDAO, ReviewDAO and CouponDAO. Use Connection, PreparedStatement, ResultSet, DriverManager and SQLException.
PreparedStatement ps = connection.prepareStatement(
    "SELECT * FROM products WHERE product_id = ?"
);
ps.setInt(1, id);
ResultSet rs = ps.executeQuery();
Do not concatenate user input into SQL strings. Use PreparedStatement.

26. Security Requirements
•	Use PreparedStatement.
•	Hash passwords before database storage.
•	Use HttpSession for login state.
•	Use AuthenticationFilter for protected customer pages.
•	Use AdminFilter for /admin/*.
•	Validate input on the server.
•	Calculate order totals on the server; do not trust browser-submitted totals.
•	Never store passwords in cookies.

34. Conclusion
ShopSphere is a single capstone project that connects the supplied RTU syllabus with a modern E-Commerce use case. Students should first build the core web application end-to-end and then add the Swing, networking, RMI and syllabus-specific JSP demonstrations. This approach keeps the project achievable while ensuring that the final demonstration covers the major Advanced Java topics.
